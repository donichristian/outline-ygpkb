# Outline YGPKB — User Guide (Non-Technical)

## What is this?

Outline YGPKB is our internal knowledge base. It is a private, team-only
version of [Outline](https://www.getoutline.com), an open-source wiki where
employees can write, share, and find documents together in one place.

Use it to:

- Store company policies, how-to guides, and meeting notes
- Keep project documentation in one shared location
- Search across all internal documents instantly
- Write pages collaboratively with your team in real time

## Getting access

1. Ask your administrator to add your email address to the workspace.
2. Sign in at the internal URL you were given (for the dev environment this
   is `http://localhost:3000`).
3. Choose your sign-in option (Google, Microsoft 365, Slack, email, or
   single sign-on, depending on what your organization configured).

## Using the knowledge base

### Collections

Content is organized into **Collections** (like folders). Each collection has
a set of pages. Only members you add to a collection can see its pages, unless
the collection is shared with the whole workspace.

### Documents

Inside each collection you create **Documents**. Documents are pages you can
format with headings, lists, tables, images, code blocks, and links.

- Open a collection, click **New document**, and start typing.
- Use `/` while typing to insert images, tables, embeds, and more.
- Drag pages in the sidebar to reorder them or nest them into sub-pages.

### Search

Use the search bar at the top (or press `Cmd/Ctrl + K`) to search across all
documents you have access to.

### Sharing and permissions

- Collections can be private to a few people or public to the whole workspace.
- Individual documents can be shared via a link with people inside or, if
  enabled, outside the company.
- Read-only access can be granted to users who should not edit.

### Real-time editing

Multiple people can edit the same document at the same time. Changes are
saved automatically — there is no "Save" button.

## Frequently asked questions

**I forgot my password / cannot sign in.**
Contact your administrator or use the "forgot password" link on the sign-in
page, depending on your sign-in provider.

**Where did my uploaded file go?**
Attachments are stored inside the document they were uploaded to. Look in the
document or search for it.

**Can I use it on my phone?**
Yes. The web interface works on mobile browsers.

**I found a bug or want a feature.**
Report it to the internal IT/admin contact listed by your team.

## Rules of thumb

- Put new documents in the right collection, with a clear title.
- Prefer one topic per document.
- Archive outdated documents instead of deleting them when possible.
