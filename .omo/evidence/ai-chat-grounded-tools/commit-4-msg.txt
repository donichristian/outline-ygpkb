refactor(mcp): extract a shared document body reader

Moves the full-document body read (heading scan, case-insensitive heading-text section match, chunking, 20000/60000 caps, both paging shapes) from server/mcp/tools/fetch.ts into server/commands/documentReader.ts with two entry points: readLoadedDocument (already-loaded, already-authorized doc, no second lookup/policy check - external tool path) and readDocumentById (id + user, authorizes through the document loader - AI tool path in todo 5). A separate anchor-based section lookup is exposed for the new AI tool (getAnchorContent) and is NOT used by the external wrapper, which keeps heading-text matching. External fetch output is byte-identical (11/11 fetch.test.ts + 9/9 documentReader.test.ts pass unmodified), including the unmatched-section and missing-id error messages. Capture test (fetch.capture.test.ts) records before/after payloads.
